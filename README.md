# Basketball Stats Tracker

> **Demo version.** All teams, players, venues and stats in this repository are fictional ("Harbour City BC", "Riverside Hawks", …). Bring your own Supabase project to run it.

A web app for a basketball coaching staff: live in-game scouting, box scores,
advanced stats, lineup analysis, opponent scouting reports and an internal
player ranking. It is the demo version of a tool used by a club's staff
during a real season.

## Features

**Live game**
- Courtside live scouting: track possessions, defensive coverages, play situations and turnovers with a few taps
- Real-time live view for other staff members, powered by Supabase Realtime
- Shot charts by court zone with heat colouring

**Box scores & stats**
- Per-game box scores generated by a Postgres trigger from the raw event log (`game_events` → `player_game_stats`)
- Shooting and efficiency: FG%, FT%, eFG%, TS%, AST/TO, TOV%, Game Score, PIR
- Team ratings: estimated possessions, pace, offensive/defensive rating, rebound rates
- Lineup analysis: stints, top lineups and player plus/minus
- "Verified" flag per game that resets automatically if any event changes after review

**Team & players**
- Team dashboard: record, leaderboards, season table, momentum, head-to-head, lineups and shot chart
- Player pages with season and per-game numbers
- Internal accountability ranking (positive plays, defensive errors, rule breaches, bad shots, turnovers) per game or per season

**Scouting**
- Opponent scouting reports organised by situation category, with embedded video clips (YouTube / Hudl)
- Print-friendly report layout

**Staff & security**
- Supabase Auth login (staff only, no public sign-up)
- Row-level security on every table; staff accounts can work on the head coach's data through a shared-ownership model

## Tech stack

| | |
|---|---|
| Framework | Next.js 16 (App Router, Server Components), React 19, TypeScript |
| UI | Material UI + Tailwind CSS 4 |
| Backend | Supabase — Postgres, Auth, Realtime, row-level security, SQL triggers (`@supabase/ssr`) |
| Testing | Vitest — 79 unit tests for the stats engine, event logic and live scouting |

## Project structure

```
app/(app)/        games, live scouting & live view, team dashboard, players, ranking, scouting, season, roster
components/       box score, shot chart, court diagram, dashboard and scouting widgets
lib/stats/        stat formulas (basic, PIR, ratings, lineups, aggregation) + tests
lib/              event model, live scouting, shot zones, video embeds, Supabase clients
supabase/         migrations (schema, triggers, RLS, realtime) and fictional seed data
```

## Getting started

1. Create a project at [supabase.com](https://supabase.com/dashboard).
2. Copy the env file and fill in the project URL and anon key:
   ```bash
   cp .env.local.example .env.local
   ```
3. Apply the migrations:
   ```bash
   npx supabase login
   npx supabase link --project-ref <your-project-ref>
   npx supabase db push
   ```
4. Create a user in **Authentication → Users** with the email `demo@example.com` (there is no public sign-up page).
5. Load the fictional data in the Supabase SQL editor: first `supabase/seed_test_data.sql` (team, opponent, season, roster), then `supabase/seed_demo_half_season.sql` (nine finished games and one live game).
6. Run the app:
   ```bash
   npm install
   npm run dev      # http://localhost:3000
   npm test         # Vitest
   ```
